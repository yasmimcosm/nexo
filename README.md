# NEXO 💳

**Plataforma de Serviços Financeiros**

O **NEXO** é uma plataforma financeira simulada desenvolvida com foco em **engenharia de backend**, segurança, consistência de dados e sistemas distribuídos.

O projeto simula operações comuns de uma plataforma financeira, como contas, transferências, pagamentos e histórico de transações, buscando reproduzir desafios técnicos encontrados em sistemas financeiros reais.
